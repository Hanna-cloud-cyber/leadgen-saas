# Divine Women — thème Shopify

Thème Shopify complet (même design que `archetypes-site/`) pour vendre
« The 30 Archetypes of Women » sur womenbossworld.com via Shopify.

Pages : accueil (livre, prix, bouton d'achat, icônes, FAQ), quiz gratuit
(`page.quiz`), contact (`page.contact`), panier, et les pages légales
générées par Shopify (Réglages → Politiques).

Le bouton d'achat envoie directement au paiement Shopify (lien
`/cart/<variante>:1`).

Installation : Boutique en ligne → Thèmes → Ajouter un thème → Importer un
fichier .zip (le contenu de ce dossier zippé), puis Publier.
Le quiz est généré à partir de `archetypes-site/src/data.ts`
(snippets/divine-quiz-data.liquid).
